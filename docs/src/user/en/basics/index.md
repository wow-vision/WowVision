# Basics

These pages explain the parts of WowVision you use everywhere: how to move through a window and click its elements, how tooltips are read, how speech works, where the settings live, what alerts are, and how to change keys.

- [Using the Interface](interface.md) — moving through windows, clicking, dropdowns, edit boxes, the context menu, the cursor
- [Tooltips](tooltips.md) — reading tooltips as a whole or line by line
- [Speech and Sound](speech.md) — voice, rate, volume, interrupting speech, sounds and voice packs
- [The WowVision Menu and Settings](menu-and-settings.md) — the settings menu, per-character and account settings
- [Alerts](alerts.md) — automatic announcements and how to change them
- [Keybindings](keybindings.md) — the keybinding window

If you are new to WowVision, read [Using the Interface](interface.md) first: the same keys work in every window of the game.
