# RestedXP

Available on WoW: Forever, with the third-party leveling guide addon RestedXP Guides (RXPGuides). Without it, nothing on this page exists. Nothing of RestedXP is changed.

RestedXP's window, arrow and menus are drawn for the mouse and the eyes. WowVision reads them and leads you to the arrow's destination with its own sound beacon or routes.

## Keys

| Action | Default key | What it does |
|---|---|---|
| RestedXP Menu | Shift+F2 | Opens or closes the RestedXP screen |
| Say the RestedXP Step | Alt+F2 | Says the current step |
| Say Where the RestedXP Arrow Points | Ctrl+F2 | Direction as a clock position, side and distance |
| Sound Beacon Toward the RestedXP Arrow | Ctrl+Shift+F2 | A sound beacon to the arrow's destination; again stops it |
| WowVision Route to the RestedXP Arrow | Alt+Shift+F2 | A WowVision route there; again stops it |
| Right-Click Menu of RestedXP (Guides) | Alt+Ctrl+F2 | RestedXP's right-click menu |
| Stop Guiding, Skip, Next and Previous Step | Unbound | Set them in the keybinding window |

/wv rxp opens the screen; /wv rxp step, arrow, beacon, route and stop do the same as the keys.

## The screen

Tab moves through the guide and its active steps (each line to do is a checkbox, like RestedXP's skip box), the arrow (live reading, beacon, route, stop, and two checkboxes), moving in the guide (skip, previous, next, go to a step, the next steps), the items to use and creatures to target when RestedXP offers them, RestedXP's menu (Enter on a guide loads it), RestedXP's settings and WowVision's own two. RestedXP's page in the game's options window opens as a WowVision screen when that page is shown. Importing a guide from a copied string is in the menu, as Import a guide.

## Following the arrow

The beacon or route follows the arrow when RestedXP moves it. Recalculate the guidance when the arrow changes destination switches that off. Ignore small moves of the arrow (off) keeps the guidance while the arrow moves less than 10 yards from where it aims, for guides whose arrow drifts.

New steps are said by themselves (Say each new step, on).
