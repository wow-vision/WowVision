### All Versions
* Bags: the drag key on a bag slot places the bag you are holding, replacing the one in the slot, as Enter does. Before, it only picked up the bag that was in the slot.

### Modern
* Cooldown Manager Auras monitors: a monitor on Target now hears your own auras while you target yourself. Before, it reported them as Missing, because the cooldown manager labels an aura on you as Player even when you are your own target.
* Cooldown manager (/cdm): the manual explains the game's Lua error when you move an item while one of its tracked buffs is on you. The change is still saved; make such changes with no tracked buffs on you.
