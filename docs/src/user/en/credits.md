# Credits

First of all, I want to give huge thanks to Duugu, the creator of the Sku addon. Sku is the first addon that provided blind accessibility to World of Warcraft Classic and a majority of the features of WowVision are inspired by features in Sku. Sku helped me realize what could be done when it comes to game accessibility at this scale. I will be forever grateful for the time I was able to spend playing WoW thanks to Sku.

I would also like to thank those who helped me throughout the WowVision beta, particularly Fabien, Leo, and Duugu. Without your help and support this addon would be nowhere near as far along in development as it is now. Huge thanks to Fabien for all of the UI work for various versions of WoW Classic and to Leo for all of the work on the new mapping algorithm using WoW map data.

I would also like to thank HolyVirus2068/BlindWarriorGamer for all of the video guides he has been making throughout the beta. These are a great resource and I highly recommend using them if you are stuck with part of the game or just want to learn more about how the addon works.
